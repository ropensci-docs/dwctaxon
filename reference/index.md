# Package index

## Modify taxonomic names

- [`dct_add_row()`](https://docs.ropensci.org/dwctaxon/reference/dct_add_row.md)
  : Add row(s) to a taxonomic database
- [`dct_drop_row()`](https://docs.ropensci.org/dwctaxon/reference/dct_drop_row.md)
  : Drop row(s) of a taxonomic database
- [`dct_modify_row()`](https://docs.ropensci.org/dwctaxon/reference/dct_modify_row.md)
  : Modify row(s) of a taxonomic database
- [`dct_fill_col()`](https://docs.ropensci.org/dwctaxon/reference/dct_fill_col.md)
  : Fill a column of a taxonomic database

## Validate taxonomic names

- [`dct_validate()`](https://docs.ropensci.org/dwctaxon/reference/dct_validate.md)
  : Validate a taxonomic database
- [`dct_check_taxon_id()`](https://docs.ropensci.org/dwctaxon/reference/dct_check_taxon_id.md)
  : Check taxonID
- [`dct_check_tax_status()`](https://docs.ropensci.org/dwctaxon/reference/dct_check_tax_status.md)
  : Check that taxonomicStatus is within valid values in Darwin Core
  taxonomic data
- [`dct_check_mapping()`](https://docs.ropensci.org/dwctaxon/reference/dct_check_mapping.md)
  : Check mapping of usage taxonomic IDs
- [`dct_check_sci_name()`](https://docs.ropensci.org/dwctaxon/reference/dct_check_sci_name.md)
  : Check scientificName
